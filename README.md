# Supple-Chain-Management-Software
Supply Chain demand forecasting app built from scratch. Generates dummy data and lets you tune noise/seasonality. Includes 8 methods (SMA, WMA, SES, regression, Holt, Holt-Winters, seasonal naive, decomposition) with charts, 95% confidence intervals, and metrics (MAE, MAPE, RMSE, tracking signal). Auto-picks best via lowest MAPE.
